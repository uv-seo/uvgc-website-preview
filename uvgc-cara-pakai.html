FAQ

Pertanyaan yang Sering Diajukan

UVGC berlaku selama 1 tahun sejak tanggal penerbitan. Tanggal kedaluwarsa tertera di sisi belakang kartu. Pastikan untuk menggunakannya sebelum batas waktu tersebut.
Tergantung metode redeem. Untuk redeem online via UV App atau Web Commerce, nilai UVGC dikonversi menjadi saldo Ultra Value yang bisa digunakan bertahap. Untuk redeem offline di kasir, kebijakan partial redemption mengikuti aturan masing-masing merchant.
Jika QR Code tidak bisa di-scan, Anda masih bisa menggunakan Voucher ID yang tertera di sisi belakang kartu untuk proses redeem manual. Hubungi tim CS Ultra Voucher melalui live chat atau WhatsApp untuk bantuan lebih lanjut.
Untuk redeem online, saldo Ultra Value yang diperoleh dari UVGC bisa dikombinasikan dengan saldo UV lainnya. Untuk redeem offline, kebijakan kombinasi pembayaran mengikuti aturan merchant masing-masing.
Saldo Ultra Value tidak dapat diuangkan kembali (non-refundable). Namun, saldo dapat digunakan untuk membeli berbagai voucher digital di ekosistem Ultra Voucher selama masih dalam masa berlaku.
Daftar lengkap merchant partner tersedia di halaman Merchant di website ini, serta di dalam aplikasi Ultra Voucher pada menu "Around You". Merchant mencakup lebih dari 20.000 outlet di seluruh Indonesia.
